# Proposal: 从相册里一次找出过去拍过的贴纸和涂鸦

> State: idea · Updated: 2026-11-19

## Intent
大多数人用系统相机拍、而且平时很少路过贴纸密集的地方，新用户的收藏、地图和系列因此长时间是空的（[06 §4.5](../../../06-product-roadmap.md) 方向 A：解决低频、冷启动、召回）。让用户选一段时间或一次旅行的照片，在设备上自动找出其中的作品并抠好，确认后一次入库，地点和时间取自照片。衡量：新用户首次会话里收藏 > 1 件的比例；旅行后回访。

## Scope
In scope:
- 选择一段时间（或一个相簿）的照片，在设备上找出可能的贴纸 / 涂鸦 / 壁画并给出抠图建议。
- 逐张或批量确认、丢弃、改用其他抠法；确认后入库，地点和时间来自照片。
- 权限说明讲清「全程在设备上处理、不上传」；只授予有限访问时只扫描授权的照片。
- 大量照片时可以离开、可中断、回来继续。
Out of scope:
- 自动发布到世界地图（发布仍是逐件、由用户决定）。
- 后台自动扫描新照片（以后再议）。
- 旅行回顾卡片（方向 B）。

## Capabilities
- `library-import` (new)

## Decisions
- 2026-10-21: 方向 A 列为扩大使用面的第一步 — 见路线图 §4.5（上架 v1.0 拿数据之后）。
- 2026-11-19: 暂不做，只保留提案 — 批量扫描相册工作量很大；先做 10–12。

## Open questions
1. 先做真机验证（固定一批真实相册照片，测识别准确率和耗时）再定范围，还是直接按「选时间段 → 确认」做最小版？（选项：a 先验证 / b 直接做）
2. 放在第一次打开的路径里（空图鉴「从过去的照片里找」），还是只放在采集入口？（选项：a 两处都放 / b 只放采集入口）
3. 这是 Pro 功能还是免费？（选项：a 免费，作为获客 / b 免费有数量上限，Pro 无限）
