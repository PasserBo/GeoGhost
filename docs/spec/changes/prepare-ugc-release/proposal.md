# Proposal: 让带线上功能的版本通过审核并合规上架

> State: accepted · Updated: 2026-11-12

## Intent
开启 UGC 后，隐私标签、隐私政策、年龄分级、社区规则和审核备注都要跟着变，否则会被拒或误导用户。v1.0 的隐私标签是「不收集数据」，这一版必须如实改写。

## Scope
In scope:
- 隐私政策：收集什么（昵称、公开的抠图、模糊位置、日期、点赞收藏举报记录）、存在哪、怎么删除。
- App Store 隐私营养标签更新。
- 年龄分级问卷更新（UGC）。
- 社区规则（EULA）公开页与 App 内链接。
- 审核备注：说明无需登录即可体验发布、举报、屏蔽，以及审核员测试内容为何「审核中」。
- 支持页增加申诉与删除数据说明。
Out of scope:
- 商店文案改版（另起变更）。

## Capabilities
- 无（合规与文档，没有 App 内行为变化；App 内行为在 2–6 号变更里）。
