## Purpose
第一次抠图的人在编辑器里就能学会两个基本手势（点一下、画圈），取景时知道该拍多近。

## ADDED Requirements

### Requirement: 前几次进入编辑器时演示基本手势
编辑器在没有选区、也没有建议时，前三次打开必须用动画演示「点一下」和「画一圈」，直到用户第一次触碰；之后同一次编辑中第一次选择失败时必须再显示一次。

#### Scenario: 第一次打开
- **GIVEN** 用户从未打开过编辑器，照片里没有建议
- **WHEN** 编辑器打开
- **THEN** 画面中间出现手指点一下再画一圈的动画和一句说明

#### Scenario: 第一次触碰
- **GIVEN** 演示正在显示
- **WHEN** 用户点、长按或画圈
- **THEN** 演示消失

#### Scenario: 失败后
- **GIVEN** 用户还没选中任何东西
- **WHEN** 第一次选择失败
- **THEN** 演示再出现一次

#### Scenario: 用过几次之后
- **GIVEN** 用户已经打开过三次编辑器
- **WHEN** 编辑器打开且没有建议
- **THEN** 只显示静态的一句说明，没有动画

### Requirement: 手势说明先列基本操作
手势说明必须先列出「点一下」「画一圈」「框选」三项基本操作，其余手势列在后面。

#### Scenario: 打开手势说明
- **WHEN** 用户从编辑器菜单打开手势说明
- **THEN** 第一组是基本操作：点一下、画一圈、框选

### Requirement: 取景框提示拍摄距离
相机运行时，取景框中间必须显示一个提示框和「让作品占满这个框」的说明；它不拦截对焦和拍照。

#### Scenario: 打开相机
- **WHEN** 相机开始取景
- **THEN** 中间显示提示框和说明，点画面仍可对焦
