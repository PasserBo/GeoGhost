# Proposal: 第一次抠图时在编辑器里直接教，在家也能用示例照片练

> State: in-progress · Updated: 2026-11-19

## Intent
编辑器唯一的说明气泡在第一次触碰后就消失，「画圈」这个最稳的手势没人会自己发现，「Gesture guide」藏在菜单里且有 10 条。新用户第一次失败时已经看不到任何提示。引导应当出现在用户要做那件事的时刻、只教最少的操作，并且让不在街上的人也能先练一次。依赖 [improve-cutout-defaults](../improve-cutout-defaults/proposal.md)：教的是改进后的操作。衡量：5 人走查中，没有人需要打开手势说明就完成第一次抠图；示例照片练习 30 秒内完成。

## Scope
In scope:
- 第一次进入编辑器（且没有建议选区时）显示一个手势演示（点一下 / 画一圈），直到用户第一次触碰；之后只在连续失败时再出现，出现几次后不再出现。
- 顶部一行提示始终显示「现在最该做的一件事」，随状态变化（未选 / 失败一次 / 失败两次 → 指向框选）。
- 图鉴空状态可以「用示例照片试试」，进入编辑器练习一张已知能抠成功的贴纸；练习结果不存进收藏，结束时引导用户用自己的照片。
- 手势说明页只把最常用的两三条放在最上面，其余折叠。
- 取景框里一个静态提示框：让作品占满它。
Out of scope:
- 打开 App 时的多页欢迎轮播（不做）。
- 首次打开的空状态、权限时机（[improve-first-run](../improve-first-run/proposal.md)）。
- 视频教程、帮助中心。

## Capabilities
- `capture-editor` (modified)

## Decisions
- 2026-11-19: 示例照片从用户自己拍的贴纸里选了 3 张抠图干净的，由易到难各演示一种情况：① 蓝色泡泡字（涩谷，灯柱上只有一张，最容易）；② 黑猫（涩谷，周围贴满别的贴纸，演示「从一堆里只选一张」）；③ 青色海狸（神宮前，旁边紧挨熊猫贴纸，演示「分开挨在一起的两张」）。原图已转正、长边 2048、去掉全部元数据（无 GPS / 时间 / 设备），连同理想抠图放在本地 `CoachingSamples/`（gitignore，与 AppStoreScreenshots 同理：含第三方街头艺术，不进公开仓库）。
- 2026-11-19: 方向认可（me：「every single of these ideas looks great」）。
- 2026-11-19: 示例照片只用于练习，不存进收藏；练习结束引导用户去拍 / 选自己的照片 — 收藏只放用户自己的作品。
- 2026-11-19: 取景框先只做静态提示框，不做实时检测 — 耗电；照片仍常失败再考虑。
- 2026-11-19: 转 accepted；示例照片由 me 提供。

## Open questions
- 示例照片是别人的街头作品：打包进 App 前是否需要换成自己的贴纸，或征得作者同意（App Store 截图已经公开展示过这些作品）。
- 示例照片用哪几张？需要 me 提供有权使用的真实贴纸照片（自己拍的），2–3 张，难度递进。（实现前必须有）
