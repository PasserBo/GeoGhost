# Proposal: 第一次抠图时在编辑器里直接教，在家也能用示例照片练

> State: in-progress · Updated: 2026-11-19

## Intent
编辑器唯一的说明气泡在第一次触碰后就消失，「画圈」这个最稳的手势没人会自己发现，「Gesture guide」藏在菜单里且有 10 条。新用户第一次失败时已经看不到任何提示。引导应当出现在用户要做那件事的时刻、只教最少的操作，并且让不在街上的人也能先练一次。依赖 [improve-cutout-defaults](../improve-cutout-defaults/proposal.md)：教的是改进后的操作。衡量：5 人走查中，没有人需要打开手势说明就完成第一次抠图；示例照片练习 30 秒内完成。

## Scope
In scope:
- 第一次进入编辑器（且没有建议选区时）显示一个手势演示（点一下 / 画一圈），直到用户第一次触碰；之后只在连续失败时再出现，出现几次后不再出现。
- 顶部一行提示始终显示「现在最该做的一件事」，随状态变化（未选 / 失败一次 / 失败两次 → 指向框选）。
- 图鉴空状态可以「用示例照片试试」，进入编辑器练习一张已知能抠成功的贴纸；练习结果不存进收藏，结束时引导用户用自己的照片。
- 手势说明页只把最常用的两三条放在最上面，其余折叠。
- 取景框里一个静态提示框：让作品占满它。
Out of scope:
- 打开 App 时的多页欢迎轮播（不做）。
- 首次打开的空状态、权限时机（[improve-first-run](../improve-first-run/proposal.md)）。
- 视频教程、帮助中心。

## Capabilities
- `capture-editor` (modified)

## Decisions
- 2026-11-19: 示例不打包别人的作品，也不拿别人的贴纸让 AI 改（仍是衍生作品） — 用户：「我们现在没有自己品牌的贴纸，可能需要在已有的图片上进行ai生成才行了」。改为 2–3 张 GeoGhost 原创贴纸（以 App 图标里的幽灵为基础：异形模切 / 圆形徽章 / 「GEOGHOST」泡泡字），合成到用户照片中不含他人作品的灯柱、墙面背景上；「一堆里选一张」「两张挨着」的场景里其他贴纸也用原创的。合成图必须在真机上确认 Vision 能抠出来。`CoachingSamples/` 里的 3 张只作为构图参考。
- 2026-11-19: 示例照片从用户自己拍的贴纸里选了 3 张抠图干净的，由易到难各演示一种情况：① 蓝色泡泡字（涩谷，灯柱上只有一张，最容易）；② 黑猫（涩谷，周围贴满别的贴纸，演示「从一堆里只选一张」）；③ 青色海狸（神宮前，旁边紧挨熊猫贴纸，演示「分开挨在一起的两张」）。原图已转正、长边 2048、去掉全部元数据（无 GPS / 时间 / 设备），连同理想抠图放在本地 `CoachingSamples/`（gitignore，与 AppStoreScreenshots 同理：含第三方街头艺术，不进公开仓库）。
- 2026-11-19: 原创示例照片做好了（agent）。贴纸全部由代码画（[scripts/make-coaching-samples.swift](../../../../scripts/make-coaching-samples.swift)，基于 App 图标的幽灵），原图在 [stickers/](stickers/)：幽灵异形模切（带地图钉和星星，白边）、圆形徽章（GEOGHOST / STREET FINDS）、泡泡字（GEOGHOST、BOO），共 9 种配色。合成到用户照片里的素面区域（只裁不含他人作品的部分；① 灯柱上原有的一张贴纸用其下方的素面灯柱盖掉、再被幽灵盖住），加了透视、照片的明暗和偏色、软阴影、磨损和纹理。成品在本地 `CoachingSamples/brand/`（gitignore；背景是用户照片，无元数据，长边 2048）：① 涩谷灯柱上一张橙色幽灵；② 金属箱上五张原创贴纸，目标是橙色幽灵；③ 锌板灯柱上徽章和米色幽灵并排。另有理想抠图、目标遮罩和 `samples.json`（目标中心点 / 框，归一化，左上原点——演示手势指向这里）。
- 2026-11-19: Vision 验证（macOS 上的 `VNGenerateForegroundInstanceMaskRequest`，[scripts/check-coaching-cutout.swift](../../../../scripts/check-coaching-cutout.swift)，IoU 在 Vision 的 512×512 遮罩上算）：① 默认选择（画面中心）就是目标，IoU 0.99；② 找到 5 个实例，默认选中的是别的贴纸，点目标中心得到目标，IoU 0.99；③ 找到 2 个实例，默认选中徽章，点幽灵得到幽灵，IoU 0.99。注意：③ 只要两张贴纸真正重叠或白边相接，Vision 就把它们合成一个实例（点、画圈都分不开，只能手动裁剪）——所以 ③ 的两张之间留了一条细缝（在 2048 宽的图里再靠近约 25px 就合并）。「挨在一起」演示的是「默认选错了，点你要的那张」，不是重叠分离。macOS 与 iPhone 的模型可能不同，**真机仍需确认**：三张在 App 里各自能抠出、③ 在真机上没有合并、提示指向的点正确。
- 2026-11-19: 方向认可（me：「every single of these ideas looks great」）。
- 2026-11-19: 示例照片只用于练习，不存进收藏；练习结束引导用户去拍 / 选自己的照片 — 收藏只放用户自己的作品。
- 2026-11-19: 取景框先只做静态提示框，不做实时检测 — 耗电；照片仍常失败再考虑。
- 2026-11-19: 转 accepted；示例照片由 me 提供。
