# Proposal: 把一个系列做成图鉴样式的分享卡，带路线缩略地图

> State: in-progress · Updated: 2026-11-23

## Intent
世界地图这类玩法要靠大量用户内容支撑，所以宣传方式定为：像未来自发分享的用户那样，在 Reddit 等社区直接发在日本拍到的贴纸，不发下载链接、不直接宣传 App。现在的分享卡只能展示一件作品，体现不出 GeoGhost 独有的一点——同一款贴纸在不同地方被再次遇见。系列卡把「遇见几次、相隔多远、走过哪些地方」放进一张图里，让看的人一眼明白这张贴纸跨了多远；分享的人点一下就能得到一张能发的图。衡量：系列卡帖子相对单张卡帖子的点赞 / 评论，以及评论里问「这是什么 App」的次数。

## Scope
In scope:
- 系列页新增分享入口；相遇 2 次以上的系列可以生成系列卡，只有 1 次的继续用现有的单张卡。
- 竖版 4:5 卡片，图鉴样式：上方一张大图，下方是数据面板——编号（用户的第几个系列）、系列名字、类型、统计数据。
- 统计数据：相遇次数、地点数、时间跨度、最远两次相遇之间的距离（公里和英里都写，因为看图的人和分享的人不在同一个地区）。
- 两种系列卡，在分享页左右滑动选择：一种把最远距离放得最显眼，一种把相遇次数放得最显眼。默认先显示哪一种自动决定——相遇点跨了城市时是距离卡，否则是次数卡。
- 分享页对所有卡片类型通用：以后新增卡片类型时，选择、预览和导出的方式不变。单件作品的分享卡也改用同一个分享页。
- 路线缩略地图：真实地图，范围跟随相遇点的分布——都在一个区就显示区那么大，同城显示城市，跨城市显示国家范围；上面画出路线和相遇点。
- 定位小图：地图一角放一个很小的国家轮廓并标出位置，让不熟悉当地的人知道这是哪里；地图本身已经是国家范围时省掉。
- 分享的人可以决定四件事：用哪种卡、用哪一次相遇的图作封面（默认最新一次）、大图用抠图还是原图（默认抠图）、系列名字（分享页里可以直接起名或改名）。什么都不改也能直接分享，其余全部自动。
- 隐私：卡片上的相遇点位置与公开发布时一样只精确到街区（约 100 m）；缩略地图有最小范围，不会放大到能认出具体哪栋楼。
- 没有网络、画不出地图时，仍能生成一张不带地图的卡。
Out of scope:
- 区域合集卡（一个地区的多张贴纸放在一张图里）——地区怎么划分、怎么展示还没想清楚，一张图塞很多贴纸也看不清细节；以后单独讨论。
- 横版（左右分栏）卡片——手机上看太小；以后要发适合横图的平台时再议。
- 关闭 GeoGhost 标记、地名改成罗马字——先保持现状。
- 范围说明文字（例如「3 次相遇，都在东京」）——第一版不写。
- 别人拍到的同一款贴纸（世界地图上的数据）并入系列卡——这里只用自己的收藏。

## Capabilities
- `share-card` (new — 仓库里还没有任何主规格，这次只写系列卡和通用分享页的行为)

## Approach
地图范围直接由相遇点的坐标决定，不依赖行政区划，所以现有数据就够。「跨了城市」的判断也用相遇点之间的距离，不用地名：现在只存了街区、城市一级和国家，而且东京 23 区在数据里各算一个城市，靠地名会把同城误判成跨城。具体的距离界线在设计时定。

## Decisions
- 2026-11-23: 宣传先走 Reddit，发原图（未抠图或整根电线杆）配分享卡，不发下载链接 — 模拟未来自发分享的用户，而不是硬广。
- 2026-11-23: 现有单张卡的 GeoGhost 标记和汉字地名保持不变 — 标记很小，不算硬广；地名先不动。
- 2026-11-23: 区域合集卡暂缓 — 地区划分和多贴纸展示都难设计，且细节看不清。
- 2026-11-23: 系列卡做成图鉴样式 — 一个系列只需要一张大图，适合放数据。
- 2026-11-23: 竖版 4:5，上图下数据，不做左右分栏 — 手机上横图太小，数据文字看不清。
- 2026-11-23: 用缩略地图展示路线，范围跟随收藏分布（区 / 城市 / 国家）— 比纯文字更直观地体现贴纸跨了多远。
- 2026-11-23: 画法定为真实地图加定位小图，不画行政区轮廓 — 只有国家一级的轮廓数据放得进 App；区和城市的边界数据太大，联网查询又要把坐标发给第三方。
- 2026-11-23: 卡片上最显眼的数字自动选——跨城市时放最远距离，同城时放相遇次数 — 一张卡只讲一句话，放最让人想问的那个数字（调研第 2 条）。
- 2026-11-23: 第一版不写范围说明（「都在东京」这类）— 地图加定位小图已经回答了在哪里；也不用补存都道府县 / 州一级。
- 2026-11-23: 大图默认用抠图，分享的人可以用一个开关换成原图 — 抠图保证图鉴样式和版面稳定；原图保留街头的样子（调研第 3 条）。
- 2026-11-23: 样稿的两种卡都保留，作为分享页里左右滑动选择的卡片类型；自动规则只决定默认先显示哪一种 — 给分享的人一点选择权，他们会更喜欢自己分享的内容。取代当天早些时候「最显眼的数字自动选」的决定。
- 2026-11-23: 开始做；分享功能要解耦、能继续加卡片类型 — 已确定分享会有多种类型。
- 2026-11-23: 地图标识按保守做法先做（保留快照自带的内容，加一行文字「Maps: Apple」，不画 Apple 标志），上架前由 me 读一遍许可协议的地图附件确认。
- 2026-11-23: 不另加「Maps: Apple」文字 — 实际生成后发现快照左下角自带 Apple 的 Maps 标志，它本身就是署名；卡片原样保留它，其他内容避开它。
- 2026-11-23: 同意下载 Natural Earth 国家轮廓数据并打包进 App — 定位小图需要；精简后 208 KB。
