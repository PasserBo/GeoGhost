## Purpose
在地图页浏览所有人公开的贴纸：缩小时看到各个区域有多少，放大后看到一张张贴纸，点开看详情。

## ADDED Requirements

### Requirement: 我的与世界切换
地图页必须能在「我的」和「世界」之间切换：「我的」显示自己收藏的全部作品，「世界」显示所有人公开的贴纸。第一次打开时选中「我的」，之后记住上一次的选择。

#### Scenario: 切换到世界
- **GIVEN** 用户在地图页的「我的」
- **WHEN** 用户选择「世界」
- **THEN** 地图上显示当前区域内所有人公开的贴纸，自己私密的作品不再显示

#### Scenario: 再次打开地图页
- **GIVEN** 用户上次离开地图页时选的是「世界」
- **WHEN** 用户重新打开 App 并进入地图页
- **THEN** 仍然是「世界」

### Requirement: 世界地图显示的内容
世界地图必须只显示已公开的贴纸，包括用户自己公开的；审核中、未通过、被隐藏或已撤回的贴纸都不得显示。

#### Scenario: 自己审核中的贴纸
- **GIVEN** 用户有一张审核中的贴纸
- **WHEN** 用户在世界地图上查看它所在的区域
- **THEN** 世界地图上没有这张贴纸

#### Scenario: 自己已公开的贴纸
- **GIVEN** 用户有一张已公开的贴纸
- **WHEN** 用户在世界地图上查看它所在的区域
- **THEN** 能看到它

### Requirement: 缩小时按区域聚合
地图缩小到城市或更大范围时，贴纸必须按区域聚合显示，每个聚合显示该区域的贴纸数量和其中一张的缩略图；点按聚合时地图放大到该区域。

#### Scenario: 点按聚合
- **GIVEN** 世界地图缩小到整个东京，涩谷附近显示一个数量为 12 的聚合
- **WHEN** 用户点按它
- **THEN** 地图放大到涩谷附近，显示更细的聚合或单张贴纸

### Requirement: 放大后显示单张贴纸
地图放大到街区范围时，每张贴纸必须以缩略图单独显示在它的大致位置上；点按打开它的详情。

#### Scenario: 点按一张贴纸
- **GIVEN** 地图放大到一个街区，显示了 3 张贴纸
- **WHEN** 用户点按其中一张
- **THEN** 打开这张贴纸的详情

### Requirement: 他人贴纸的详情
他人贴纸的详情必须显示抠图、大致区域、发现日期、类型和发现者昵称，不显示任何发布范围以外的信息（见 `publishing` › 公开内容的范围）。

#### Scenario: 打开详情
- **WHEN** 用户打开一张别人公开的贴纸
- **THEN** 看到抠图、区域名、发现日期、类型和发现者昵称

### Requirement: 空区域
当前区域没有公开的贴纸时，世界地图必须说明这里还没有公开的贴纸。

#### Scenario: 没有贴纸的区域
- **GIVEN** 当前区域没有任何公开的贴纸
- **WHEN** 世界地图加载完成
- **THEN** 显示这里还没有公开的贴纸

### Requirement: 离线与加载失败
世界地图加载失败时必须说明原因并提供重试；已经显示的贴纸保留在地图上。

#### Scenario: 拖动地图时断网
- **GIVEN** 世界地图上已显示一些贴纸，然后网络断开
- **WHEN** 用户把地图拖到新的区域
- **THEN** 提示需要网络连接并提供重试，之前显示的贴纸仍在
