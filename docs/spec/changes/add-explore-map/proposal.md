# Proposal: 在世界地图上浏览其他人公开的贴纸

> State: accepted · Updated: 2026-11-12

## Intent
线上社区的价值要让人「看见」：打开世界地图就能看到别人在各个城市发现的贴纸。浏览完全免费、不需要身份。衡量：Explore 周访问率 ≥ 40%（06 §8）。

## Scope
In scope:
- 世界地图入口；缩小时按区域显示数量，放大后显示贴纸缩略图。
- 贴纸详情：抠图、区域、日期、类型、发布者昵称。
- 空区域、离线、加载失败时的表现。
- 自己的公开贴纸在世界地图上也能看到。
Out of scope:
- 筛选（城市 / 时间 / 风格），按热度排序。
- 发布者个人主页（阶段 2）。
- 「附近」提醒。

## Capabilities
- `explore-map` (new)

## Decisions
- 2026-11-12: 地图聚合在服务端按网格完成，客户端只按视口请求 — 避免把整片区域的帖子都下载到手机。

- 2026-11-12: 世界地图放在现有地图页，用「我的 / 世界」切换 — 底部保持 5 个标签，用户在熟悉的地方发现别人的贴纸。
