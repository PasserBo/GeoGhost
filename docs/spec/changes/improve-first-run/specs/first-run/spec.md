## Purpose
第一次打开 GeoGhost 的人能马上知道做什么，不在街上也能收下第一件作品；系统权限在需要的时候、带着理由出现；地图一打开就能看到别人收集的作品。

## ADDED Requirements

### Requirement: 空图鉴提供拍照和从相册选两条路
图鉴里还没有作品时，必须同时提供「拍一张」和「从相册选一张」两个同等的入口；从相册选不需要任何权限。

#### Scenario: 第一次打开
- **GIVEN** 图鉴里没有作品
- **WHEN** 用户打开图鉴
- **THEN** 看到说明和两个按钮：拍一张、从相册选一张

#### Scenario: 从相册选
- **GIVEN** 图鉴里没有作品
- **WHEN** 用户点「从相册选一张」并选了一张照片
- **THEN** 直接进入抠图，不出现任何权限请求

#### Scenario: 不选就返回
- **GIVEN** 用户打开了相册选择器
- **WHEN** 用户取消
- **THEN** 回到空图鉴，什么都没变

### Requirement: 定位在第一次按快门时才请求
App 必须在用户第一次按快门时才请求定位权限，请求里说明用途（记录这件作品是在哪里遇到的）；打开取景框时只请求相机权限。

#### Scenario: 第一次打开取景框
- **GIVEN** 用户从未被问过定位
- **WHEN** 用户打开取景框
- **THEN** 只出现相机权限请求，取景框底部说明按快门时会记录地点

#### Scenario: 第一次按快门
- **GIVEN** 用户从未被问过定位
- **WHEN** 用户按快门
- **THEN** 照片照常拍下，随后出现定位请求

#### Scenario: 已经拒绝
- **GIVEN** 用户拒绝过定位
- **WHEN** 用户按快门
- **THEN** 不再请求，作品保存时没有地点

### Requirement: 保存时可以补上当前位置
照片没有地点、而此刻能拿到定位时，保存单必须提供「用我当前的位置」；用户不点就按没有地点保存。

#### Scenario: 刚允许定位
- **GIVEN** 第一张照片拍下时还没有定位，用户随后允许了定位
- **WHEN** 保存单出现且定位已拿到
- **THEN** 地点一栏提供「用我当前的位置」，点了之后显示地名

#### Scenario: 从相册导入且照片没有地点
- **GIVEN** 导入的照片没有地点，定位可用
- **WHEN** 保存单出现
- **THEN** 同样提供「用我当前的位置」；不点则保存为没有地点

#### Scenario: 拿不到定位
- **GIVEN** 定位被拒绝或一直拿不到
- **WHEN** 保存单出现
- **THEN** 地点一栏显示没有地点，不提供该按钮

### Requirement: 诊断报告的同意在第一件作品保存之后才问
App 必须在用户有了至少一件作品之后才询问是否分享诊断报告；如果之前发生过崩溃、有报告在等待，可以提前问。

#### Scenario: 新用户第一次打开
- **GIVEN** 新安装，没有作品，没有等待中的报告
- **WHEN** 用户打开 App，或第二次打开 App
- **THEN** 不询问诊断报告

#### Scenario: 保存第一件
- **GIVEN** 用户还没决定是否分享
- **WHEN** 用户保存第一件作品并回到主界面
- **THEN** 询问是否分享诊断报告，只问这一次

#### Scenario: 已有报告在等待
- **GIVEN** 用户还没决定，上次使用时 App 崩溃过
- **WHEN** 用户打开 App
- **THEN** 询问是否分享诊断报告

### Requirement: 地图每次启动先显示世界地图
线上功能可用时，地图每次在 App 启动后必须先显示世界地图；用户切换后，在这次运行期间保持用户的选择。线上功能不可用时显示我的地图。

#### Scenario: 启动后打开地图
- **GIVEN** 线上功能可用
- **WHEN** 用户启动 App 后第一次打开地图
- **THEN** 显示世界地图

#### Scenario: 切换后再回来
- **GIVEN** 用户把地图切到了「我的」
- **WHEN** 用户去其他页面再回到地图（App 没有重新启动）
- **THEN** 仍显示我的地图

#### Scenario: 重新启动
- **GIVEN** 用户上次把地图切到了「我的」
- **WHEN** App 被关闭后重新启动，用户打开地图
- **THEN** 显示世界地图

#### Scenario: 线上功能不可用
- **GIVEN** 这台设备上线上功能不可用
- **WHEN** 用户打开地图
- **THEN** 显示我的地图，不显示切换

### Requirement: 空的系列和地图说明下一步
系列和我的地图为空时，必须说明它们什么时候会出现内容，并提供去收集的入口。

#### Scenario: 没有系列
- **GIVEN** 还没有任何系列
- **WHEN** 用户打开系列
- **THEN** 看到「同一张贴纸在两个地方收集会自动成为系列」的说明和去收集的按钮
