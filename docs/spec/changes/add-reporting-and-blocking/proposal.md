# Proposal: 举报不当内容、屏蔽用户，并在 24 小时内处理

> State: in-progress · Updated: 2026-11-12

## Intent
UGC 上架的硬性要求（审核指南 1.2），也是社区不被少数人毁掉的底线。任何人都能举报贴纸、屏蔽发布者；被多人举报的内容先自动隐藏；开发者 24 小时内处理每一条举报。

## Scope
In scope:
- 举报贴纸（选择原因，可附说明）；同一人对同一贴纸只算一次。
- 屏蔽发布者：立即看不到对方的所有贴纸；设置中可查看并解除屏蔽。
- 被不同用户举报达到门槛时自动隐藏，等待处理。
- 发布者看到自己的贴纸「未通过」。
- 开发者收到新举报与待审核的通知，并有处理流程（通过 / 隐藏 / 封禁）。
- 被封禁的用户不能再发布，其公开内容对他人不可见。
Out of scope:
- App 内审核后台（先用 Supabase 控制台 + SQL）。
- 申诉流程（先通过支持页邮件）。
- 设备级封禁、设备断言（之后评估）。

## Capabilities
- `content-safety` (new)

## Decisions
- 2026-11-11: 举报每天 20 次；3 个不同举报人自动隐藏（09 §4–§6）。

- 2026-11-12: 举报原因：几个基本原因 + 「其他」（需填写说明）。
- 2026-11-12（agent 起草，待确认）: 具体原因与顺序：色情或暴力、仇恨或骚扰、暴露他人隐私（人脸、车牌、门牌等）、广告或垃圾内容、其他；说明最多 500 字。理由：覆盖审核指南 1.2 与街拍特有的隐私风险，又足够短，一屏选完。
- 2026-11-12（agent 起草，待确认）: 举报与屏蔽入口放在世界地图贴纸详情右上角的「更多」菜单；屏蔽需要确认，确认后详情关闭；举报和屏蔽都以访客身份进行，不要求先设置昵称。理由：与发布不同，举报不对外展示任何内容，不应增加门槛。
- 2026-11-12: 用户确认上面两条（原因列表与顺序、入口位置与访客身份），按草稿执行。

## Open questions
