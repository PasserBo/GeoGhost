## Purpose
拍到或选好一张照片后，不看任何说明也能把作品抠出来存下：编辑器先给出建议，点一下就能选，失败时总有下一步。

## ADDED Requirements

### Requirement: 打开时给出建议选区
编辑器打开时，如果照片里有一个最可能的目标（只有一个合适的主体，或画面中心的主体），必须把它显示为建议，样式和已选的作品不同；用户点「使用这个抠图」或点一下建议就使用它；任何新的选择替换建议。

#### Scenario: 有一个明显的主体
- **GIVEN** 照片里有一个大小合适的主体
- **WHEN** 编辑器打开
- **THEN** 这个主体以建议的样式标出，顶部说明可以直接使用或另选
- **AND** 「使用这个抠图」可以点

#### Scenario: 直接使用
- **GIVEN** 编辑器显示着建议
- **WHEN** 用户点「使用这个抠图」
- **THEN** 进入保存，保存的是建议的那一块

#### Scenario: 另选
- **GIVEN** 编辑器显示着建议
- **WHEN** 用户在别处点一下、长按或画圈选中了另一块
- **THEN** 建议消失，只保留用户选的那一块

#### Scenario: 没有合适的主体
- **GIVEN** 照片里没有主体，或主体大到像整面墙
- **WHEN** 编辑器打开
- **THEN** 没有建议，「使用这个抠图」不可点，提示怎么选

### Requirement: 点一下就选中
在没选中的地方点一下，必须选中手指下的图案（和长按后松手的结果相同）；点已选中的一块仍是删掉它；连点两下仍是放大。

#### Scenario: 点一下
- **GIVEN** 编辑器里还没选任何东西
- **WHEN** 用户在贴纸上点一下
- **THEN** 贴纸被选中，和长按后松手一样

#### Scenario: 点不中
- **GIVEN** 手指下的图案分不出来
- **WHEN** 用户点一下
- **THEN** 震动并提示改用画圈，不选中任何东西

#### Scenario: 连点两下
- **WHEN** 用户连点两下
- **THEN** 放大或还原，不选中

### Requirement: 连续失败后提供框选
同一张照片上选择连续失败两次后，编辑器必须显示带文字的「改为框选」；框选里必须可以「使用整张照片」，存成不透明卡片。

#### Scenario: 失败两次
- **GIVEN** 用户点或长按两次都没选中
- **WHEN** 第二次失败
- **THEN** 底部出现带文字的「改为框选」，顶部提示也指向它

#### Scenario: 成功后
- **GIVEN** 已经出现了「改为框选」
- **WHEN** 用户成功选中一块
- **THEN** 提示回到正常状态

#### Scenario: 使用整张照片
- **GIVEN** 用户在框选界面
- **WHEN** 用户点「使用整张照片」
- **THEN** 整张照片作为不透明卡片进入保存
