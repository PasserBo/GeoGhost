# Proposal: 抠图编辑器先给出建议，失败也总能存下一件

> State: in-progress · Updated: 2026-11-19

## Intent
编辑器打开时什么都没选、「Use this cutout」是灰的、单击照片没有反应；长按在平面贴纸上（Vision 不返回主体时）经常选不中，失败后只有一行黄字。新用户做对了事（拍到了贴纸）却推进不下去，而且会归因为「我不会用」——这一层教学修不了。衡量：不看任何说明的新用户，对任意一张照片都能在 3 次触碰内保存一件作品（哪怕是矩形裁切）；真机基准照片集上「一次触碰就选对」的比例提高。

## Scope
In scope:
- 打开编辑器时，若有一个最可能的目标，把它显示为**建议**（样式和「已选」不同），主按钮可直接用它；任何新的选择替换建议。
- 单击未选区域就选中手指下的图案（和「长按后松手」同结果）；长按保留为「先看再定、拖动调范围」。
- 单击 / 长按失败时，自动以手指为中心换一种方式再试一次，结果作为建议给出。
- 连续失败后，底部出现带文字的「直接框选」；框选里可以「用整张照片」。没有走不下去的状态。
Out of scope:
- 引导、演示、示例照片（[add-cutout-coaching](../add-cutout-coaching/proposal.md)）。
- 替换底层分割模型（点提示分割，MobileSAM 类）：等本变更有真机数据后另起。
- 取景时的实时检测。

## Decisions
- 2026-11-19: 方向认可（me：「every single of these ideas looks great」）。
- 2026-11-19: 打开时显示建议选区，样式和已选不同，点一下才使用；任何新的选择替换它 — 推翻实现时的「不静默预选」，因为空白开局是新用户最大的卡点；建议需确认，所以不会静默选错。
- 2026-11-19: 单击选中、双击仍放大：单击稍等片刻判断是否双击（和系统照片一致）。
- 2026-11-19: 框选里提供「用整张照片」，存成不透明卡片（和现在的手动裁切一样），之后可用 Edit this piece 重抠。
- 2026-11-19: 开放问题全部回答，转 accepted。
