# GeoGhost — 商业化与线上路线图

> 状态：草案 · 2026-10-09 · 负责人：PasserBo
> 取代 [产品规格](00-product-spec.md) 第 6 节旧的「免费 50 件 + 买断」方案；第 5.2 节的多人功能在此展开。

## 1. 为什么改

旧方案：免费版最多 50 件，Pro 一次性买断解锁无限。问题：

1. **限制的是核心动作。** 收集类 App 的价值就是「收集」，卡数量等于惩罚最投入的用户，而且是在他们最上头的时候。
2. **拦截时机粗暴。** 在相机入口直接弹窗拒绝，用户眼前的贴纸存不下来，最容易导致卸载。
3. **Pro 价值模糊。**「高分辨率导出和以后的一切」说不清买到了什么。

## 2. 原则

- **收集永远免费且不限量。** 拍、抠、存、看、地图、系列——核心体验完整。
- **按「玩法深度」收费，而不是按「数量」收费。** Pro 让收藏更好看、更好整理、更安全、在社区里更有存在感。
- **浏览和基础参与免费。** 线上社区的内容越多越好，不能把看的人挡在外面。
- **有持续成本的功能（云端）才用订阅。** 本地功能保留买断。
- 不放广告，不卖数据。

## 3. 产品叙事

> **一张全世界街头贴纸的活地图。** 贴纸会被撕、被覆盖、会褪色，每一张都是限时存在的——你在记录一种正在消失的街头文化。

所有线上功能都围绕四件事：**发现、收集、记录、身份感**。

## 4. 分阶段计划

### 阶段 0 · v1.0 上架版（本地、完全免费，当前）

> 2026-10-14 决定：**v1.0 不开内购。** 先把基础功能做好、上架、实测，拿到使用数据后再开放高级功能。

- 收集、抠图、系列、地图、搜索、ZIP 导出——全部免费、不限量。
- 分享卡片只有基础样式（Field note），**固定带 GeoGhost 署名**（获客渠道）；透明 PNG 长边 1600 px。
- 代码里 Pro 已完整实现（卡片样式、去署名、原尺寸导出、Pro 介绍页、恢复购买），由 `ProStore.isPurchasingEnabled = false` 关闭：不调用 StoreKit、不显示任何 Pro 入口。Pro 专属选项是**隐藏**而不是免费送——以后收费时不会出现「拿走已有功能」的情况。
- App Store Connect 无需建内购、无需签付费协议。

### 阶段 0.5 · 开放 Pro（v1.x，看数据决定时机）

| 免费 | Pro（一次性买断，$3.99） |
|---|---|
| 不限数量的收集、抠图、系列、地图、搜索 | 分享卡片全部模板 |
| 透明 PNG 导出（长边 1600 px） | 分享卡片可去掉 GeoGhost 署名 |
| 分享卡片基础模板（带 GeoGhost 署名） | 原图分辨率透明 PNG 导出 |
| 全量 ZIP 导出、删除全部数据 | **创始会员**：未来线上 Pro 的优惠/赠送期（见 §6） |

- 开启方式：在 App Store Connect 建内购 → 签付费 App 协议 → `isPurchasingEnabled = true` → 随版本提交内购。
- **早期用户回馈**：Pro 推出前安装的用户可用 `AppTransaction.originalAppVersion` 可靠识别，可以送一段 Pro 试用或折扣，替代原本「早买早享」的创始会员说法。
- 付费入口：设置页 Pro 区、分享卡片中锁定的模板/去署名开关。**不在相机入口拦截任何东西。**
- 付费墙只写已经上线的权益；「创始会员」以「承诺未来优待」的方式描述，不承诺具体功能和日期（审核 2.3.1 / 3.1.2）。
- 开放的判断依据：D7 留存 ≥ 25% 且每活跃用户每周新增 ≥ 3 件——说明核心体验成立，值得在上面叠付费功能。

### 阶段 1 · 线上 MVP（验证有没有人愿意分享）

- **发布**：从自己的收藏里挑选公开，**默认私密**。坐标模糊到街区级（≈100 m 网格），去掉 EXIF，避免暴露行动轨迹。
- **世界地图（Explore）**：浏览他人公开的贴纸，聚合显示。
- **贴纸详情**：抠图、城市、时间、发现者昵称。
- **点赞 / 收藏到「灵感夹」**。
- **举报 + 屏蔽 + 审核**：UGC 上架硬性要求（审核指南 1.2）——举报内容、屏蔽用户、上传前端侧过滤、24h 内处理举报的流程、EULA 中的零容忍条款。
- 身份：Sign in with Apple；昵称 + 头像（可用自己的一张贴纸）。
- 一键撤回所有公开内容；隐私政策更新。

### 阶段 2 · 让人回来（社交与身份）

- **个人主页**：公开图鉴、城市数、发现数。
- **关注**发现者，动态 feed。
- **同款贴纸合并 →「贴纸迁徙地图」**：不同用户在不同城市拍到同一款贴纸，用局部特征匹配串起来，显示「这张贴纸被 37 人在 12 个城市看到」以及时间线。**这是最有记忆点、最难被复制的功能。**
- **首位发现者徽章**：某款贴纸第一个上传的人。

### 阶段 3 · 玩法与社区

- **「还在吗？」**：路过别人记录过的贴纸时确认它仍在 / 被撕 / 被覆盖 → 贴纸有了生命周期。
- **城市图鉴与挑战**：「涩谷 30 款」、月度主题。
- **艺术家认领**：贴纸作者认领自己的作品，展示作品在全球的分布。对艺术家很有吸引力，也是获客渠道。
- 数字贴纸交换 / 赠送（远期再评估）。

### 本地功能的持续补强（与线上并行）

- **成就 / 徽章**：第一个系列、10 个城市、连续一周有收集。
- **「一年前的今天」/ 月度回顾**：召回通知，顺带推分享卡片。
- 高级整理：智能系列、自定义标签、按城市/时间筛选、统计（去过多少街区、最常出没区域）。
- 地图图层：热力图、足迹轨迹、「附近还没收集的」提醒。
- 抠图进阶：手动精修画笔、批量处理、换背景 / 贴纸画布。
- 外观：备用 App 图标、主题。
- iCloud 私有同步与备份。

## 7. 技术与运营要点

- **后端选型**（阶段 1 前定）：
  - **CloudKit 公共库**：免运维、免费额度大、身份即 iCloud；但无服务端计算，地理查询和跨用户特征比对要在客户端做，Android/网页困难。
  - **Supabase**（Postgres + PostGIS + Storage + Edge Functions）：地理聚合、迁徙地图的跨用户匹配、审核后台都更顺；以后做网页版也方便。
  - 倾向：**阶段 1 用 Supabase**，私有同步仍用 CloudKit（数据留在用户自己的 iCloud，隐私叙事更好）。
- **审核**：上传前端侧 Vision 检测（NSFW 粗筛、人脸 / 车牌模糊）；举报队列 + 人工处理；被举报次数阈值自动隐藏。
- **隐私**：上传前剥离 EXIF；坐标模糊；可一键撤回全部公开内容；隐私营养标签与隐私政策同步更新。
- **冷启动**：上线前自己 + 种子用户先铺满 3–5 个城市（东京、上海、柏林……）的内容，空地图最劝退。
- **年龄分级**：开启 UGC 后从 4+ 调整为 12+ 或 17+（视过滤能力）。

## 7.5 v1.0 怎么收集数据

v1.0 App 内**没有任何分析 SDK**，隐私标签是「不收集数据」。可用的数据来源：

| 来源 | 能看到 | 成本 |
|---|---|---|
| App Store Connect → App Analytics | 展示、下载、会话数、活跃设备、**留存（D1/D7/D28）**、来源渠道（仅统计同意与开发者共享的用户，一般占多数） | 零代码 |
| Xcode Organizer | 崩溃、卡顿、启动时间、耗电、磁盘写入（MetricKit 聚合） | 零代码 |
| TestFlight | 测试员截图反馈、崩溃附言、每个构建的安装/会话数 | 零代码 |
| 评分与评论、支持页 issue | 定性反馈 | 零代码 |

**拿不到的**：每周新增件数、分割一次成功率、分享卡片使用率等**App 内行为指标**。如果需要，候选方案是隐私友好的匿名统计（如 TelemetryDeck，无 IDFA、不关联用户），但要同步改隐私标签（「使用数据 → 产品交互，不关联身份」）和隐私政策——**待决**。
