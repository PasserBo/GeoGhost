## 1. 一句话定位

**GeoGhost 是一本「城市街头的贴纸图鉴」**：路上看到有意思的贴纸、涂鸦、壁画，举起手机一拍，App 自动把作品从背景中抠出来，连同拍摄地点、时间一起收进你的图鉴；同一张贴纸在不同城市再遇到时，App 会自动把它们归为一个「系列」，让你看到这张贴纸走过的路线。

## 2. 为什么做这个

- 街头贴纸/涂鸦是一种**流动的、无署名的城市文化**。同一个作者的贴纸会出现在东京、柏林、纽约的电线杆上，但没有任何工具在记录这个网络。
- 现有替代品（相册、Instagram、Google 相册）保存的是**整张照片**，不是「那张贴纸」本身。用户想要的是**一本图鉴**，而不是一堆照片。
- 「收集」本身有游戏性：宝可梦式的「集齐」冲动 + 城市探索 + 地图足迹。

## 3. 目标用户

| 画像 | 场景 | 核心诉求 |
|---|---|---|
| **城市漫游者**（主要） | 旅行/通勤时习惯拍街头细节 | 拍得快、存得好看、能回顾走过的路 |
| **贴纸/涂鸦爱好者** | 关注特定艺术家，追踪他们的作品分布 | 同一设计自动归类、地图上看分布 |
| **街头文化研究者/摄影师**（次要） | 需要带地点时间的系统化归档 | 元数据完整、可导出 |

## 4. 核心用户旅程（Happy Path）

1. 打开 App → 落在**图鉴页**，底部 Tab 栏中央是醒目的相机入口（一次点击进入取景；不在启动时直接开相机，避免首启权限弹窗轰炸与发热）。
2. 对着贴纸按下快门 → 0.5s 内出现分割结果：贴纸被高亮抠出，背景变暗。
3. 若默认选中的不是想要的对象，**点一下**目标即可切换；多张贴纸可多选。
4. 点「收藏」→ 出现极简确认卡：自动填好类型（贴纸/涂鸦/壁画）、地点（反地理编码）、时间；可选加备注。
5. 回到**图鉴页**：新作品以透明背景的「贴纸」形态出现在网格里，像一本真正的贴纸册。
6. 若这张贴纸与之前收藏的某张设计相同，卡片角标显示「×2」，进入即可看到两次相遇的地图连线。
7. **地图页**：所有收藏落在地图上，缩放自动聚合；点选查看。

**关键体验指标**

- 从按下快门到看到分割结果：**≤ 1 s**（iPhone 12 及以上）
- 从快门到完成收藏：**≤ 3 次点击**
- 分割一次成功率（无需手动干预）：**≥ 80%**（贴纸类）

## 5. 功能范围

| 采集 | 端侧前景实例分割（Vision），点选/多选目标，边缘羽化 | P0 |
| 采集 | 分割失败时的回退：手动矩形/套索裁切 | P0 |

| 图鉴 | 透明背景贴纸网格（sticker album），按时间/地点/类型分组 | P0 |
| 图鉴 | 详情页：抠图 + 原图切换、地图、地址、时间、设备、备注、标签 | P0 |

| 系列 | 同一设计自动归类（Vision FeaturePrint 相似度），手动合并/拆分 | P0 |
| 系列 | 系列页：所有相遇点的地图连线 + 时间线 | P1 |
| 地图 | MapKit 全量展示，聚合，点选预览 | P0 |

| 分享 | 单张贴纸导出为透明 PNG / 分享卡片（含地点水印可选） | P1 |

### 5.2 v1.x（上架后迭代）—— 多人

- **公开地图（Explore）**：用户可选择把某件作品「公开」，公开作品匿名（仅显示昵称）出现在所有人的探索地图上。
- **全球系列**：同一设计在不同用户之间自动关联（服务端 FeaturePrint 比对），形成「这张贴纸被 37 人在 12 个城市看到」。
- **关注艺术家/系列**：新相遇推送。
- 技术：CloudKit Public Database，无自建服务器；用户身份即 iCloud 账号，无需注册。

### 5.3 明确不做（Non-goals）

- 不做社交 Feed、评论、点赞、私信。
- 不做用户生成的地点打卡/签到玩法。
- 不做 Android（v1 阶段）。
- 不做任何服务端图像处理；分割/识别全部端侧完成。
- 不做「帮用户找到作者」等版权敏感功能。

## 6. 商业模式

- **免费**：完整采集、图鉴、地图，上限 50 件作品。
- **Pro（¥1,500 / $9.99 一次性买断）**：无限作品、iCloud 同步、高分辨率透明 PNG 导出、iMessage 贴纸导出、分享卡片去水印。
- 不放广告，不卖数据。理由：目标用户是审美敏感群体，广告会毁掉「图鉴」的质感；一次性买断在这个品类（相机/工具类）转化率优于订阅。

## 7. 设计原则

1. **贴纸就是主角**：所有列表默认展示抠出的透明贴纸，而非原始照片；背景使用微妙的纸张纹理/纯色，让贴纸像贴在册子上。
2. **零等待**：所有 ML 端侧、异步；先展示再补全（先出分割，地址稍后填入）。
3. **元数据是免费的礼物**：位置、时间、朝向、设备来自 EXIF/传感器，不让用户填任何能自动得到的信息。
4. **克制**：一页只做一件事；不弹引导、不弹评分、不要多余的权限。

## 8. 隐私与合规要点

- 位置仅在采集时读取（`WhenInUse`），存储在本地/用户自己的 iCloud；公开分享（v1.x）时必须二次确认且默认模糊到 100 m。
- 分割/分类/相似度全在端侧完成，图像不离开设备（除用户主动开启 iCloud 同步）。
- 街头涂鸦拍摄可能涉及他人作品：App 内不声称版权归属；导出功能仅供个人使用；App Store 描述明确定位为「个人图鉴/笔记」。
- 需要的权限：相机、位置（使用时）。相册通过 `PhotosPicker` 无需权限。

## 9. 成功指标（上架后 90 天）

- D7 留存 ≥ 25%
- 每活跃用户每周新增收藏 ≥ 3 件
- 分割一次成功率 ≥ 80%（通过本地匿名统计「是否手动重选/重裁」得到，可关闭）
- Pro 转化率 ≥ 4%（触达 50 件上限的用户中）
